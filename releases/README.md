# FrameScope releases

`FrameScope_v0.1.0-debug.apk` is the debug build tested on the target Android 8.1 watch.

Install it with Android's package installer or ADB:

```bash
adb install FrameScope_v0.1.0-debug.apk
```

After installation, start Shizuku, grant FrameScope Shizuku access, enable overlay permission, and start the FPS overlay from the app.
